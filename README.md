# 学生信息管理系统（控制台版）

Java 实现的控制台学生信息管理程序，练习面向对象、集合、异常处理、文件读写与代码分层。

## 功能

- 添加学生（学号、姓名、性别、电话，空格分隔）
- 显示全部学生
- 按学号查找
- 删除学生
- **数据持久化**：启动时自动从文件读取，退出时保存，关掉程序数据不丢

## 技术栈

- Java 21
- `ArrayList` 存储数据
- `Scanner` 读取输入
- `split("\\s+")` 拆分输入
- `PrintWriter` / `BufferedReader` 读写文件

## 数据存储

程序启动时读取项目根目录的 `students.txt`，退出时把当前数据整体写回。
文件不存在时以空列表启动，首次运行会自动创建。

每行一条记录，逗号分隔：

```
20250403,陈生,男,789166
```

> `students.txt` 是运行产生的数据文件，已加入 `.gitignore`，不纳入版本管理。

## 如何运行

1. 用 IntelliJ IDEA 打开本项目
2. 运行 `src/com/hnufe/contacts/Main.java`
3. 按控制台菜单输入数字选择功能

示例输入：

```
20250403 陈生 男 789166
```

## 项目结构

```
src/com/hnufe/contacts/
├── Main.java       # 程序入口、菜单、各功能流程、文件读写
└── Student.java    # 学生实体类
```
