# 学生信息管理系统（控制台版）

Java 实现的控制台学生信息管理程序，用来练习面向对象、集合、异常处理与代码分层。

## 功能

- 添加学生（学号、姓名、性别、电话，空格分隔）
- 显示全部学生
- 按学号查找
- 删除学生
- 退出

## 技术栈

- Java 17
- `ArrayList` 存储数据
- `Scanner` 读取输入
- 字符串分割 `split("\\s+")`

## 如何运行

1. 用 IntelliJ IDEA 打开本项目
2. 运行 `src/com/hnufe/contacts/Main.java`
3. 按控制台菜单输入数字选择功能

示例输入：

```
20250403 陈生 男 789166
```

## 项目结构

```
src/com/hnufe/contacts/
├── Main.java       # 程序入口、菜单、各功能流程
└── Student.java    # 学生实体类
```
